# Voice and audio workflows

**Verification:** These are workflow categories, **not verified step-by-step UI instructions**. Controls and export formats must be confirmed against running builds.

## Prepare

1. Obtain explicit authorization to use any person's voice or recording.
2. Check recording quality, format, and the model's input requirements.
3. Preserve the original media and choose a safe project storage location.

## Workflows to document and verify

- New project and project reopening
- Model selection and model download
- Voice library and authorized voice cloning
- Speech generation and regeneration
- Transcription, translation and dubbing where implemented
- Editing, playback and audio export
- Queue management, cancellation, restart and recovery

Each verified workflow will include exact navigation, screenshots, sample inputs, expected output, common errors and recovery steps. Until then, do not rely on unverified feature claims.
