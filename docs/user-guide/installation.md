# Installation and first run

**Verification:** Not yet platform-verified. Do not use upstream installers as fork installers.

## Before installing

1. Confirm your operating system is supported by a verified BetterVoiceStudio release.
2. Review the release's prerequisites, checksum/signature and model storage requirements when published.
3. Back up any existing voice projects before upgrading or replacing an installation.

## Installation

The fork's installation steps, installer names, permissions and first-run prompts are **pending real Windows, macOS and Linux acceptance testing**. They will be added as screenshots and executable acceptance evidence become available.

## First-run checklist

- Verify the app launches and displays BetterVoiceStudio identity.
- Confirm project and model storage locations before downloading large assets.
- Review privacy and model-license information.
- Test a small authorized audio workflow before committing important work.

## Upgrades and uninstall

Migration, rollback, preserved user data and uninstall behavior remain **unverified**. Never delete existing project folders as a troubleshooting shortcut.
