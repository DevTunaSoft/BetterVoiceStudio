# Models and resources

**Verification:** UI navigation, model downloads and model compatibility are not yet acceptance-tested on the modernization branch.

## Model selection checklist

1. Identify the task you need: speech generation, transcription, voice conversion or another supported workflow.
2. Review the model's license, source, intended use and required hardware.
3. Confirm disk space and available memory before downloading.
4. Prefer the application's built-in model management when verified; do not assume every model supports every workflow.
5. Start with a small, authorized sample and verify audio quality and resource usage.

## Troubleshooting

If a model fails to load, record the exact error, OS, available RAM/VRAM, model identifier and app version. Do not repeatedly reinstall or delete models without first preserving relevant data. Exact repair steps will be added after model lifecycle tests.
